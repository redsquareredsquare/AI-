# 線上訂單 → Google Sheet（Apps Script）

結帳送出的訂單會以 POST 送到 Apps Script Web App，驗證後寫入試算表的「訂單」工作表，並回傳訂單編號（例如 `DG-0001`）。

## 一、部署（約 5 分鐘）

1. 建立一份 Google 試算表（例如「日常餃子所 訂單」）。
2. 在試算表選單點 **擴充功能 › Apps Script**。
3. 把 `gas/Code.gs` 的內容整段貼到編輯器，取代預設的 `myFunction`，按「儲存」。
4. （選用）在 `Code.gs` 把 `NOTIFY_EMAIL` 改成店家信箱，每筆新訂單會寄信通知。
5. 點右上角 **部署 › 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 按「部署」，第一次會要求授權，依提示完成。
7. 複製產生的 **網頁應用程式網址**（格式為 `https://script.google.com/macros/s/.../exec`）。
8. 用瀏覽器開啟該網址，若看到 `{"ok":true,"service":"orders",...}` 代表服務正常。

## 二、接上網站

打開 `index.html`，找到下面這一行，把網址貼進引號中：

```js
const ORDER_ENDPOINT = "";
```

網址留空時，網站維持示範模式（不會寫入試算表）。設定後提交會真的寫入 Sheet。

> 之後修改 `Code.gs` 時，要到「部署 › 管理部署作業」建立**新版本**，網址才會更新為最新程式。

## 三、試算表欄位

| 欄位 | 內容 |
|---|---|
| 訂單編號 | `DG-0001` 起算，依列數遞增 |
| 建立時間 | 台北時間 |
| 聯絡人 / 電話 | 結帳表單填寫內容 |
| 取餐方式 | 內用、外帶、宅配 |
| 地址 | 僅宅配填寫 |
| 品項明細 | 每行一項：品名 x數量（單價） |
| 數量合計 / 金額 | 伺服器計算 |
| 狀態 | 預設「待確認」，可自行改為「已出餐」等 |

## 四、測試（不經過網站）

```bash
curl -L -X POST "你的網頁應用程式網址" \
  -H "Content-Type: text/plain;charset=utf-8" \
  -d '{"name":"測試","phone":"0912345678","fulfillment":"外帶","items":[{"id":"pork-potstickers","name":"招牌豬肉鍋貼","price":95,"quantity":2}]}'
```

成功會回傳 `{"ok":true,"orderId":"DG-0001"}`，並在試算表多一列。測完請刪除測試列。

## 五、已知限制

- **沒有線上收款**：只記錄訂單，付款與取餐仍需門市確認。
- **金額以前端單價計算**：有技術能力的人可能竄改單價。要防止，需在 `Code.gs` 加入完整價目表並比對商品 id（已在程式中標記 TODO）。
- **網址是公開的**：任何人都能送出訂單。程式已有基本格式驗證與蜜罐欄位，但不能完全防止濫用。
- **不要把 Apps Script 網址當成密碼**，也不要在前端放任何金鑰。
