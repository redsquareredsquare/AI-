# 棍破山河

原創水墨風 2D 動作遊戲：石猿持棍，闖過三回妖境，單挑三位妖王。單一 HTML 檔，不需要建置，用瀏覽器開 `index.html` 即可（字型來自 Google Fonts，離線時會退回系統宋體）。

## 操作

| 動作 | 鍵盤 | 手把 |
|---|---|---|
| 移動 | A / D | 左搖桿、十字鍵 |
| 跳躍 | 空白 / W | A |
| 輕棍（四段） | J | X |
| 蓄力重棍 | 按住 K | Y |
| 空中迴旋 / 落棍 | 空中 J / K | X / Y |
| 閃避 | L / Shift | B |
| 識破後反擊 | 識破後 J | X |
| 定身術 / 分身術 | I / O | RB / LB |
| 葫蘆回血 | R | LT |
| 土地祠修習 | 靠近按 F | Back |
| 暫停 / 聲音 / 畫面震動 | Esc / M / V | Start |

手機：橫置，畫面上有觸控按鍵。

## 設定

標題選單最後一項「設定」，或暫停畫面的「設定」按鈕（關閉後回到暫停）。W / S 選擇、A / D 調整、Esc / L 返回；觸控點 ◀ ▶ 調整、點「返回」離開；手把用十字鍵與 B。變更立即生效並自動儲存。

| 項目 | 選項 |
|---|---|
| 音樂音量 / 音效音量 | 0–100%，每格 10% |
| 畫面震動 | 開 / 關（同 V 鍵） |
| 傷害數字 | 開 / 關（關閉時不顯示命中與受傷數值，識破、定！等提示照常） |
| 觸控按鈕大小 | 小 / 中 / 大（只影響觸控裝置） |

M 鍵靜音獨立於音量設定。

## 玩法重點

- **識破**：敵人攻擊判定出現前的約 0.2 秒內閃避，會觸發慢動作，接著按 J 反擊。被閃過的攻擊不會再補傷害。
- **棍勢**：輕棍命中累積，滿一格後蓄力重棍會把棍勢耗盡，傷害更高。
- **靈蘊**：擊敗敵人獲得，在土地祠升級 9 項技藝。倒下不會損失。
- **盾兵**正面擋輕棍，要用重棍、落棍、反擊，或繞背。
- **三回**：黑松嶺（蒼牙狼王）→ 竹海寒寺（玄鶴禪仙）→ 焚天谷（熔山魔君）。
- **難度**：遊歷 / 修行 / 渡劫，開新旅程時選擇。
- **二周目**：通關後保留技藝，敵人更強。
- **Boss 挑戰**：單挑任一 Boss 或三王連戰，記錄最佳時間與無傷。
- **故事**：天上三盞明燈墜入人間，得燈之妖各自稱王，石猿逐一把燈送回天上。開新旅程時播放直書序章，每回開頭有卷首詩，Boss 倒下時留下遺言，通關前播放終章。土地祠的土地公會給一句提點。
- **百妖錄**：擊敗妖怪即可收錄（共 10 頁），每頁有繪製的妖怪、稱號、一首七言絕句、來歷與應對方法。

## 存檔

使用瀏覽器 `localStorage`：

| key | 內容 |
|---|---|
| `gunpo-save` | 旅程進度（章節、技藝、靈蘊、檢查點） |
| `gunpo-best-<難度>` | 旅程最佳通關時間 |
| `gunpo-rush-<1/2/3/g>-<難度>` | Boss 挑戰最佳時間 |
| `gunpo-rushnh-…` | 無傷擊敗標記 |
| `gunpo-lore` | 百妖錄已收錄的妖怪 |
| `gunpo-diff` / `gunpo-mute` / `gunpo-shake` | 偏好設定 |
| `gunpo-vol-music` / `gunpo-vol-sfx` | 音量（0–100） |
| `gunpo-dmgnum` / `gunpo-padsize` | 傷害數字（1/0）、觸控按鈕大小（0 小 / 1 中 / 2 大） |

## 平衡測試

`tools/bot.js` 是用腳本玩家跑完整遊戲的無頭測試（需要 Playwright）：

```bash
node game/tools/bot.js <局數> <難度，如 0,1,2> <反應延遲倍率>
```

輸出各難度通關率、各章節與 Boss 的死亡次數，以及被什麼招式打中最多。改動戰鬥或敵人數值後可用來檢查有沒有難度斷崖或卡死。

## 程式結構（`index.html` 內的單一腳本）

資料表（`DIFF` / `CH` / `UPG` / `ESS`）→ 音訊（程式合成）→ 輸入 → 選單與存檔 → 實體與玩家 → 敵人 AI（每種敵人一個 `update*`）→ 繪圖（`draw*`，背景與角色皆用 Canvas 繪製）→ HUD → `render` 與主迴圈。`window.__game` 提供測試用的掛鉤（`step`、`halt` 等）。
