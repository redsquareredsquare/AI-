# 棍破山河

原創水墨風 2D 動作遊戲：石猿持棍，闖過三回妖境，單挑三位妖王。單一 HTML 檔，不需要建置，用瀏覽器開 `index.html` 即可（字型來自 Google Fonts，離線時會退回系統宋體）。

## 操作

| 動作 | 鍵盤 | 手把 |
|---|---|---|
| 移動 | A / D | 左搖桿、十字鍵 |
| 跳躍 | 空白 / W | A |
| 輕棍（四段） | J | X |
| 蓄力重棍 | 按住 K | Y |
| 空中迴旋 / 落棍 | 空中 J / K | X / Y |
| 閃避 | L / Shift | B |
| 識破後反擊 | 識破後 J | X |
| 定身術 / 分身術 | I / O | RB / LB |
| 精魄（魄滿施展；未滿時切換） | U（S + U 切換） | RT |
| 葫蘆回血 | R | LT |
| 土地祠修習 | 靠近按 F | Back |
| 暫停 / 聲音 / 畫面震動 | Esc / M / V | Start |

手機：橫置，畫面上有觸控按鍵。

## 設定

標題選單最後一項「設定」，或暫停畫面的「設定」按鈕（關閉後回到暫停）。W / S 選擇、A / D 調整、Esc / L 返回；觸控點 ◀ ▶ 調整、點「返回」離開；手把用十字鍵與 B。變更立即生效並自動儲存。

| 項目 | 選項 |
|---|---|
| 音樂音量 / 音效音量 | 0–100%，每格 10% |
| 畫面震動 | 開 / 關（同 V 鍵） |
| 傷害數字 | 開 / 關（關閉時不顯示命中與受傷數值，識破、定！等提示照常） |
| 觸控按鈕大小 | 小 / 中 / 大（只影響觸控裝置） |
| 畫面效果 | 高 / 低：底片顆粒、色調、光束與地面霧氣。手機預設為低 |

M 鍵靜音獨立於音量設定。

聲音全部即時合成，不用音檔：三回各有自己的配樂（黑松嶺古箏與簫、竹海寒寺鐘聲木魚與笛、焚天谷戰鼓與嗩吶），Boss 戰與第二階段節奏加快；打擊、閃避、識破、敵人出招前的預兆都有對應音效。

## 玩法重點

- **識破**：敵人攻擊判定出現前的約 0.2 秒內閃避，會觸發慢動作，接著按 J 反擊。被閃過的攻擊不會再補傷害。
- **棍勢**：輕棍命中累積，滿一格後蓄力重棍會把棍勢耗盡，傷害更高。
- **靈蘊**：擊敗敵人獲得，在土地祠升級 9 項技藝。倒下不會損失。
- **精魄**：每擊敗一位妖王就得到牠的魄。命中、反擊與識破會積蓄「魄」，滿了按 U 施展；未滿時按 U 切換已有的精魄。施展時短暫無敵。妖王倒下時，牠的魄會化作光球飛入石猿體內。Boss 挑戰與二周目三魄齊備。

| 精魄 | 來源 | 效果 |
|---|---|---|
| 狼魄 | 蒼牙狼王 | 化作幻狼突進，穿過路上的敵人，收尾再咬一口 |
| 鶴魄 | 玄鶴禪仙 | 揮出七枚霜羽，貫穿敵陣並定住小妖 |
| 岩魄 | 熔山魔君 | 躍起重擊地面，前方接連噴出三道熔岩柱 |

- **盾兵**正面擋輕棍，要用重棍、落棍、反擊，或繞背。
- **三回**：黑松嶺（蒼牙狼王）→ 竹海寒寺（玄鶴禪仙）→ 焚天谷（熔山魔君）。
- **難度**：遊歷 / 修行 / 渡劫，開新旅程時選擇。
- **二周目**：通關後保留技藝，敵人更強。
- **Boss 挑戰**：單挑任一 Boss 或三王連戰，記錄最佳時間與無傷。
- **故事**：天上三盞明燈墜入人間，得燈之妖各自稱王，石猿逐一把燈送回天上。開新旅程時播放直書序章，每回開頭有卷首詩，Boss 倒下時留下遺言，通關前播放終章。土地祠的土地公會給一句提點。
- **百妖錄**：擊敗妖怪即可收錄（共 10 頁），每頁有繪製的妖怪、稱號、一首七言絕句、來歷與應對方法。
- **成就**：百妖錄畫面的第二個分頁（A / D 或輕觸上方分頁切換），共 15 項，旅程與 Boss 挑戰皆可達成，達成時會提示「成就達成：…」：

| 成就 | 條件 |
|---|---|
| 初識破 | 首次以閃避識破敵招 |
| 反客為主 | 累計施展反擊 10 次（跨局累計） |
| 一黑松嶺 / 二竹海寺 | 旅程中擊敗第一、二回的妖王 |
| 棍破山河 | 擊敗熔山魔君，走完旅程 |
| 渡劫者 | 以渡劫難度走完旅程 |
| 不飲一口 | 旅程中一場 Boss 戰從開始到擊敗都沒喝葫蘆 |
| 毫髮無傷 | Boss 挑戰中無傷擊敗一位妖王（三王連戰的每一位也算） |
| 三王伏誅 | 完成三王連戰 |
| 技藝圓滿 | 任一項技藝修習至圓滿 |
| 百妖齊錄 | 百妖錄收齊 10 頁 |
| 定身墜鶴 | 玄鶴在空中時以定身術將牠打落（「墜！」） |
| 魄動 | 首次施展精魄 |
| 三魄歸一 | 狼、鶴、岩三種精魄都施展過（跨局累計） |
| 魄滅群妖 | 一次精魄擊倒三隻以上的妖怪 |

## 存檔

使用瀏覽器 `localStorage`：

| key | 內容 |
|---|---|
| `gunpo-save` | 旅程進度（章節、技藝、靈蘊、檢查點、裝備的精魄） |
| `gunpo-best-<難度>` | 旅程最佳通關時間 |
| `gunpo-rush-<1/2/3/g>-<難度>` | Boss 挑戰最佳時間 |
| `gunpo-rushnh-…` | 無傷擊敗標記 |
| `gunpo-lore` | 百妖錄已收錄的妖怪 |
| `gunpo-ach` | 成就：`{u:[已達成 id], c:累計反擊次數, s:施展過的精魄（位元）}` |
| `gunpo-diff` / `gunpo-mute` / `gunpo-shake` | 偏好設定 |
| `gunpo-vol-music` / `gunpo-vol-sfx` | 音量（0–100） |
| `gunpo-dmgnum` / `gunpo-padsize` | 傷害數字（1/0）、觸控按鈕大小（0 小 / 1 中 / 2 大） |
| `gunpo-fx` | 畫面效果（1 高 / 0 低） |

## 平衡測試

`tools/bot.js` 是用腳本玩家跑完整遊戲的無頭測試（需要 Playwright）：

```bash
node game/tools/bot.js <局數> <難度，如 0,1,2> <反應延遲倍率> [rush=1,2,3] [story=1] [generic=類型]
```

- 預設跑故事模式，輸出各難度通關率、平均時間、各章節與 Boss 的死亡次數、精魄／定身／分身的平均使用次數，以及被什麼招式打中最多（`HITS`）。Boss 戰的鍵是 `招式|ps=被打中前的動作|LOWST(體力不足)|via=實際命中的判定或飛行物`，例如 `boss:leap|…|via=wave` 是被狼王跳斬的地波打中。
- `rush=1,2,3` 改跑 Boss 挑戰：經由標題選單選關（跟玩家操作相同），每場輸出勝率、勝場平均時間、平均被擊中次數與剩餘氣血；`rush=g` 跑連戰。選單沒有的 Boss（例如 `rush=4` 在第四隻 Boss 加入前）會顯示 skipped 並略過。加 `story=1` 可同時跑故事模式。
- 腳本玩家只會按鍵與放開，會讀取遊戲狀態來判斷：預測敵人的出招判定、飛行物與延遲爆發的範圍和時間，模擬幾種操作（原地、走開、跳、左右閃避、精魄）挑不會受傷又最省的一種；閃避會等到快命中才按，盡量打出識破並反擊。進攻時保留夠閃一次的體力、只在對方來不及出手時出棍，長空檔才蓄重棍，體力不足就退開回氣，安全時才喝葫蘆。
- 反應延遲倍率 1 約等於熟練玩家；數字越大看到招式越慢、閃避時機越亂（約 6 以上就幾乎反應不過來）。
- 不認識的敵人類型（例如之後新增的 Boss）會改用通用打法：依狀態名稱判斷蓄力／出招／硬直，並記住被打中的時機與距離；不認識的飛行物依座標與速度閃躲。`generic=boss,wave` 可強制把已知的敵人或飛行物當作未知來測試這套通用打法。

改動戰鬥或敵人數值後可用來檢查有沒有難度斷崖或卡死。

## 程式結構（`index.html` 內的單一腳本）

資料表（`DIFF` / `CH` / `UPG` / `ESS`）→ 音訊（程式合成）→ 輸入 → 選單與存檔 → 實體與玩家 → 敵人 AI（每種敵人一個 `update*`）→ 繪圖（`draw*`，背景與角色皆用 Canvas 繪製）→ HUD → `render` 與主迴圈。`window.__game` 提供測試用的掛鉤（`step`、`halt` 等）。
